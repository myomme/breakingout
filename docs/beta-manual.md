# Breaking Out 베타 플레이 매뉴얼

## 1. 게임 목표

Breaking Out은 3번의 레이드 동안 파밍, 전투, 생존, 탈출을 반복해서 최종 가치를 겨루는 턴제 익스트랙션 보드게임입니다.

- 각 레이드는 15페이즈까지 진행됩니다.
- 탈출에 성공하면 들고 나온 아이템 가치가 계정 기록에 반영됩니다.
- 탈출하지 못하고 사망하면 해당 레이드에서 들고 있던 아이템 가치는 잃습니다.
- 3번째 레이드 종료 후 누적 성과, 생존, 탈출 기록을 바탕으로 최종 결과가 정리됩니다.

## 2. 로비와 방

- 방 만들기: 방장이 방을 만들고 슬롯, 맵, COM 참가자를 설정합니다.
- 방 참가: 방 코드를 입력하거나 방 목록에서 참가합니다.
- 준비: 비방장 플레이어는 READY를 눌러야 게임 시작 준비가 완료됩니다.
- 장비 선택: 각 플레이어는 자기 슬롯에서 무기와 방어구를 고릅니다.

## 3. 턴 진행

내 턴에는 이동, 루팅, 공격, 탈출 같은 행동을 선택합니다. 스태미나는 행동 자원입니다.

- 걷기: 스태미나 1을 사용해 1칸 이동합니다.
- 대시: 스태미나 2를 사용해 최대 3칸 이동합니다.
- 공격: 사거리와 시야가 맞아야 하며, 보통 공격 후 턴이 종료됩니다.
- 중요한 판정은 서버가 확정한 뒤 적용됩니다.

## 4. 이동과 화면 조작

- 이동 가능한 타일은 화면에 표시됩니다.
- 타일을 누르면 내 화면에서는 즉시 임시 이동이 보이고, 서버 검증 후 확정됩니다.
- 서버가 거절하면 원래 위치로 돌아가며 이동 불가 알림이 나옵니다.
- 모바일은 한 손가락 드래그로 카메라 이동, 두 손가락 핀치로 확대와 축소를 합니다.
- 화면 버튼은 맵 전체를 넓게 확인할 때 사용합니다.

## 5. 루팅과 가방

- 상자나 루팅 타일에 접근하면 아이템을 얻을 수 있습니다.
- 시체 가방은 해당 위치에서 상호작용하면 열 수 있습니다.
- 가방은 20칸이며, 가득 찬 경우 아이템을 버리거나 교체해야 합니다.
- 보험 처리된 아이템은 가방에서 별도 표시가 유지됩니다.

## 6. 전투

- 무기마다 사거리, 피해, 주사위, 패시브가 다릅니다.
- AR은 최대 4칸, SMG는 최대 3칸, SR은 최대 8칸까지 공격합니다.
- 머리 또는 상체 HP가 0이 되면 사망합니다.
- 복부나 하체가 0인 상태에서 추가 피해를 받으면 상체 피해로 전환됩니다.

## 7. 이벤트 카드

- 4페이즈부터 이벤트 카드가 등장할 수 있습니다.
- 즉시 효과, 페이즈 효과, 보존형 효과가 섞여 있습니다.
- 보존형 이벤트는 이벤트 탭에 남고 필요한 순간 사용할 수 있습니다.

## 8. 계정과 외형

- 킬과 탈출은 경험치와 RP에 영향을 줍니다.
- 사망하면 RP가 소폭 감소합니다.
- 루팅 가치는 말 스킨, 링, 프로필 카드, 채팅 말풍선, 칭호 같은 외형 보상 구매에 사용합니다.
- 외형 보상은 밸런스에 영향을 주지 않는 방향으로 운영합니다.

## 9. 채팅, 공지, 신고

- 로비와 방에서는 로비 채팅을 사용합니다.
- 인게임에서는 작전 채팅을 사용합니다.
- 운영자 공지는 로비, 방, 인게임 어디서든 최상단 팝업으로 표시됩니다.
- 버그나 억울한 튕김이 있으면 신고 버튼으로 상황을 남겨 주세요.

## 10. 재접속

- 같은 계정으로 다시 접속하면 진행 중인 방 복귀 안내가 떠야 합니다.
- 방장이 나가거나 플레이어가 튕긴 경우 서버가 슬롯과 COM 전환을 관리합니다.
- 재접속 안내가 뜨지 않거나 게임으로 복귀되지 않으면 버그 제보로 남겨 주세요.
